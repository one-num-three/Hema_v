# 河马智能体可视化协作平台 Windows 安装说明

适用对象：Windows 用户。

本文档用于指导用户完成河马安装、首次启动、模型配置和常见问题处理。

本软件及相关文档仅供学习、研究与交流使用。

---

## 1. 安装前准备

安装前请先确认以下事项：

1. 已将安装包完整解压到本地文件夹。
2. 电脑可以正常访问网络。
3. 系统默认浏览器建议设置为 Microsoft Edge 或 Google Chrome。
4. 安装过程中请尽量不要移动安装目录。
5. 如果安装包在压缩文件内，请务必先解压，不要直接在压缩包里运行安装程序。
6. 安装目录不要包含空格、中文字符或特殊符号。

推荐安装路径示例：

```text
D:\Hema
E:\Hema
D:\hema_fix
E:\hema-agent
```

不建议放在路径过深、权限复杂、带空格、带中文字符或云同步目录中，例如：

```text
桌面\临时文件夹\新建文件夹\安装包
OneDrive 同步目录
微信临时文件目录
C:\Program Files\Hema
D:\河马安装包
D:\Hema Final
```

推荐目录命名规则：

```text
只使用英文、数字、下划线 _、短横线 -
```

例如：

```text
D:\hema
D:\hema_fix
E:\hermes_agent
```

## 2. 杀毒软件与安全说明

安装前建议临时关闭杀毒软件，或将河马安装目录加入信任区。

原因是河马安装包属于本地 AI 工具集成环境，里面包含：

- 批处理启动脚本；
- PowerShell 安装脚本；
- Python 运行环境；
- Node.js 运行环境；
- 本地 Web 页面服务；
- 本地网关服务；
- 桌面快捷方式创建逻辑。

这些行为在安全软件看来可能类似“自动安装程序”或“本地服务启动器”，容易触发启发式误报。

这不等于程序有病毒。更准确地说，是未签名本地工具包在 Windows 上常见的误报场景。

你可以用以下方式自查：

1. 安装脚本是明文文件，可以右键用记事本打开查看。
2. 主要入口文件在根目录，例如 `installer_gui.bat`、`install.bat`、`start_webui.bat`。
3. 程序默认运行在本机，不会要求用户提供系统账号密码。
4. API Key 需要用户自己在界面中填写，程序不会内置第三方模型密钥。
5. 如需联网，主要用于模型 API、依赖检查、本地服务访问和网关连接。
6. 你可以使用 Windows 防火墙、任务管理器、资源监视器查看实际联网进程。

重要说明：

河马不建议用户永久关闭杀毒软件。安装完成并确认可以正常启动后，可以重新开启杀毒软件，并把河马安装目录加入信任名单。

## 3. 开始安装

1. 打开解压后的安装包根目录。
2. 在根目录中找到：

```text
installer_gui.bat
```

3. 双击运行 `installer_gui.bat`。
4. 按照安装界面或命令行提示继续操作。
5. 首次安装可能需要几分钟，请等待安装完成。

如果 Windows 提示“是否允许运行”或“未知发布者”，确认安装包来源可信后选择继续运行。

---

## 4. 浏览器要求

河马可视化界面通过本地 Web 页面打开。

推荐使用：

- Microsoft Edge；
- Google Chrome。

请将默认浏览器设置为 Edge 或 Chrome。

设置方式：

1. 打开 Windows 设置。
2. 进入“应用”。
3. 进入“默认应用”。
4. 搜索 Edge 或 Chrome。
5. 设置为默认浏览器。

不建议使用兼容性较差或内核过旧的浏览器。

---

## 5. 首次打开后的配置

安装完成后，程序会打开河马可视化页面。

首次使用请先完成模型配置：

1. 进入模型配置或模型管理页面。
2. 创建一个新的模型配置。
3. 选择你要使用的模型服务商。
4. 填入你自己的 API Key。
5. 保存配置。
6. 等待系统加载模型配置。

说明：

- API Key 由用户自己提供。
- 不同模型服务商的 Key 不通用。
- 如果 Key 填错，模型无法正常回复。
- 如果网络不可用，模型也无法正常调用。

---

## 6. 等待网关启动

首次启动时，河马会同时启动本地 Web 服务和网关服务。

如果页面刚打开时暂时没有内容，或模型列表、网关状态没有立即显示，请先等待一段时间。

建议等待：

```text
30 秒到 2 分钟
```

如果等待很久仍然没有显示，或页面一直空白，可以尝试重启网关。

---

## 7. 重启网关

安装完成后，桌面通常会生成网关相关快捷方式。

如果页面长时间没有显示、连接失败、微信网关无响应，可以：

1. 回到桌面。
2. 找到“网关重启”或类似名称的快捷方式。
3. 双击运行。
4. 等待网关重新启动。
5. 回到浏览器刷新页面。

如果仍然无法恢复，可以尝试：

1. 关闭浏览器页面。
2. 重新双击桌面上的河马启动快捷方式。
3. 等待服务启动。
4. 再次打开页面。

---

## 8. 微信网关说明

微信网关用于连接本地河马能力与微信消息入口。

使用前请注意：

1. 确保微信处于登录状态。
2. 确保网络正常。
3. 确保网关服务正在运行。
4. 如果之前测试发送过很多消息，可能存在排队或历史消息处理现象。
5. 如果网关行为异常，优先使用桌面快捷方式重启网关。

微信网关属于本地连接能力，实际可用性会受到微信客户端状态、系统权限、网络环境和安全软件拦截影响。

## 9. 常见问题

### 页面打开后是空白

处理方式：

1. 确认默认浏览器是 Edge 或 Chrome。
2. 等待 30 秒到 2 分钟。
3. 刷新浏览器。
4. 双击桌面“网关重启”快捷方式。
5. 重新打开河马页面。

### 安装程序被杀毒软件拦截

处理方式：

1. 确认安装包来源可信。
2. 临时关闭杀毒软件，或把河马目录加入信任区。
3. 重新运行 `installer_gui.bat`。
4. 安装完成后重新打开杀毒软件。

### 模型不回复

处理方式：

1. 检查 API Key 是否正确。
2. 检查模型服务商是否选择正确。
3. 检查网络是否正常。
4. 等待片刻后重试。
5. 如仍失败，重新创建模型配置。

### 网关连接不上

处理方式：

1. 双击桌面网关重启快捷方式。
2. 等待服务启动。
3. 刷新页面。
4. 确认安全软件没有拦截本地服务。
