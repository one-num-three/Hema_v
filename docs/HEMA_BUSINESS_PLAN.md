# 河马 Hema / Hermes 可视化 AI Agent 商业计划书

版本：v1.2
定位：面向 Windows 用户的可视化 AI 工作中枢
关键词：Windows 一键安装、Hermes 可视化、微信网关、PPT 一键生成、多源信息聚合、本地场景服务、专属 Agent、模型与算力底座、Skill 工作流

## 1. 执行摘要

河马 Hema 是基于 Hermes Agent 打造的 Windows 可视化 AI Agent 产品。我们要做的不是又一个聊天机器人，也不只是一个 PPT 生成工具，而是一个真正能被普通 Windows 用户安装、连接、操作和交付成果的 AI 工作中枢。

我们已经形成了清晰的产品闭环：

```text
Windows 一键安装
→ Hermes 可视化工作台
→ 微信网关触达用户
→ 多模型能力接入
→ Skill 工作流执行真实任务
→ PPT、图片、文档、文件夹等交付物输出
```

河马的第一性价值非常明确：让普通用户不需要懂部署、不需要懂命令行、不需要理解复杂模型配置，也能把 AI Agent 用在真实工作里。

从产品结构上看，河马不是单点功能，而是围绕 Windows 和微信入口形成四条主产品线：

1. **多源信息聚合**：整合外部行情、行业新闻、兴趣资讯、每日动态，同时沉淀个人日程、聊天记录、生活想法和长期记忆。
2. **内容产出**：围绕 PPT、图片、动画视频、漫剧、图文海报等交付物，形成从主题理解、素材组织、视觉生成到文件输出的闭环。
3. **本地场景服务**：面向 Windows 用户处理开发环境部署、系统运维、批量文件处理、格式转换、本地数据管理和知识库检索。
4. **专属 Agent**：持续理解用户的本地资源、工作流、兴趣偏好、资讯动态和日程安排，输出学习推荐、知识总结、智能提醒和个性化内容。

这四条产品线共同指向一个更大的判断：AI Agent 的入口不应该只停留在聊天窗口，而应该进入用户的信息流、文件系统、内容生产和本地工作场景。

第一阶段我们聚焦四个确定性抓手：

1. **Windows 一键安装**：解决普通用户最难跨过的安装门槛。
2. **Hermes 可视化**：让 Agent 从命令行能力变成可操作产品。
3. **微信网关连接**：接入国内最高频的用户触达入口。
4. **PPT 一键生成**：从主题拆解、用户核验、逐页生图到最终 PPT 文件夹输出，形成可展示、可传播、可付费的标杆场景。

更重要的是，我们已经与**同橙 OPC 算力超市达成合作协议**。这意味着河马不是只停留在前端体验或单一模型封装，而是具备进一步整合模型、算力、API 接入与成本控制的基础条件。产品侧有 Windows 与微信入口，能力侧有 Hermes Agent 与 Skill 工作流，供给侧有同橙 OPC 算力超市作为算力和模型生态协同资源。

河马的判断很直接：下一代 AI 工具不会停留在“更会聊天”，而会进入“更会完成任务”。我们要占住的就是国内 Windows 普通用户和轻量团队的 AI Agent 入口。

## 2. 市场判断

### 2.1 Windows 是最现实的生产力入口

大量国内办公、教育、培训、中小企业、政企和个人创作者仍以 Windows 电脑为主要生产工具。对这些用户来说，AI Agent 如果还要求安装 Python、Node、配置 API Key、修改环境变量和运行命令行，就天然停留在小众圈层。

河马选择 Windows 一键安装，是一个明确的商业判断：**谁能让普通 Windows 用户用起来，谁就能打开 Agent 的大众市场。**

### 2.2 微信是国内最强的 AI 助理入口

国内用户的任务、沟通、文件流转和客户关系大量发生在微信里。微信不是一个可有可无的渠道，而是国内用户最自然的工作入口。

河马接入微信网关后，AI Agent 不再只是电脑里打开的一个窗口，而是可以被微信消息触发、可以把结果返回到微信、可以成为用户随身可调用的任务助理。

这带来三个商业价值：

- 提高使用频率：用户不用主动打开软件也能触发任务。
- 提高产品粘性：AI 助手进入用户日常沟通链路。
- 提高场景扩展性：客服、销售、社群、个人助理、文件处理都能通过微信入口延展。

### 2.3 AI Agent 的机会在“交付物”

过去一轮 AI 产品的核心是问答。下一轮 AI 产品的核心是任务执行和交付物。

用户不是只需要一段回答，而是需要：

- 一份能发给客户的 PPT
- 一套课程大纲和课件
- 一份项目方案
- 一批宣传图
- 一个整理好的文件夹
- 一个能持续执行的微信助理
- 一个能反复复用的工作流

河马的产品逻辑不是“问 AI 一个问题”，而是“让 AI 把一个工作做完”。

### 2.4 模型能力会成为基础设施，体验和场景才是入口

模型能力会持续增强，但普通用户不会直接消费“模型参数”。用户消费的是安装体验、任务入口、结果质量、成本稳定性和交付速度。

河马把模型能力放到底层，把用户体验和 Skill 工作流放到上层，并通过同橙 OPC 算力超市的合作增强模型与算力供给能力。这让河马可以在不同模型、不同成本、不同任务之间做更灵活的调度，而不是被单一模型路线锁死。

## 3. 用户痛点

### 3.1 装不上

大部分 Agent 项目对普通用户来说第一步就失败了。安装环境、依赖、API Key、命令行、模型配置都是阻碍。

河马用完整 Windows 一键安装包解决这个问题。用户要的不是教程，而是能直接运行的软件。

### 3.2 用不明白

很多 Agent 很强，但交互方式仍然偏开发者。普通用户不知道有哪些能力，也不知道怎么组合工具。

河马通过可视化界面和 Skill 系统，把复杂能力变成清晰入口：PPT 生成、微信连接、模型配置、文件处理、内容产出，都可以被包装成用户能理解的功能。

### 3.3 离工作太远

很多 AI 工具回答得不错，但离最终工作成果还差很远。用户还要自己复制、排版、整理、配图、生成文件。

河马强调交付闭环，尤其是 PPT 一键生成：

```text
主题输入
→ 内容拆解
→ 用户确认
→ 逐页视觉生成
→ PPT 自动组装
→ 输出 PPTX + 图片子文件夹
```

这不是“生成一点内容”，而是“完成一个交付物”。

### 3.4 模型成本和模型选择复杂

模型越来越多，普通用户很难判断哪个模型适合文字、哪个模型适合生图、哪个模型便宜、哪个模型稳定。

河马通过模型底座、Grsai 生图接入、新 API/中转能力，以及同橙 OPC 算力超市合作，把模型和算力能力沉到系统里，让用户面对的是任务，而不是一堆模型参数。

## 4. 产品方案

### 4.1 产品定位

河马 Hema 是面向 Windows 用户的可视化 AI 工作中枢。

一句话说明：

```text
用户一键安装河马，通过可视化界面或微信入口，把 AI 模型能力变成信息聚合、内容产出、本地服务、专属 Agent 和自动化交付物。
```

### 4.2 产品架构：一入口、四引擎、三底座

河马的产品架构可以概括为：

```text
一入口：Windows 可视化工作台 + 微信网关
四引擎：多源信息聚合、内容产出、本地场景服务、专属 Agent
三底座：Hermes Agent、Skill 工作流、同橙 OPC 算力与模型供给
```

**多源信息聚合引擎**
河马可以把外部信息和内部信息放到同一个 AI 工作流里。外部信息包括股市行情、行业新闻、兴趣资讯、每日动态；内部信息包括个人日程、聊天内容、生活想法、工作资料和长期记忆。它的价值不是简单收藏信息，而是让 Agent 能持续理解用户正在关心什么、最近发生了什么、下一步应该提醒或产出什么。

**内容产出引擎**
内容产出不是单一的“写一段文案”，而是面向交付物的完整流水线。河马可以围绕 PPT、图片、动画视频、漫剧、图文海报等内容形态，调度文案、设计、视频、校对等子 Agent 分工执行，再通过递归迭代完成整合交付。PPT 一键生成是这一引擎的第一标杆场景。

**本地场景服务引擎**
河马贴近 Windows 用户真实桌面场景，处理系统与环境运维、开发环境一键部署、硬件驱动软件优化、系统监控与故障排查、批量文件处理、格式转换、内容批量编辑、资料分类归档和本地知识库检索。这部分能力让河马从“网页 AI 工具”变成“本地工作助手”。

**专属 Agent 引擎**
河马会逐步把用户的本地资源、工作流、兴趣偏好、外部资讯和日程安排沉淀为个人上下文，形成专属 Agent。它可以输出学习推荐、知识总结、智能提醒、个性化内容和知识图谱关联推荐。长期看，专属 Agent 是留存和复购的关键，因为它越用越懂用户。

### 4.4 标杆场景：PPT 一键生成

PPT 是河马最适合率先打穿的商业化场景，因为它同时满足高频、强痛点、强展示、强付费意愿。

用户输入一个主题后，河马可以完成：

```text
PPT 内容主题拆解 Skill
→ 输出页面结构表
→ 用户核验大纲
→ PPT 逐页生图 Skill
→ 调用 Grsai / 模型生图
→ PPT 图片整合 Skill
→ 输出最终 PPT 文件夹
```

最终交付：

```text
final/
├── xxx.pptx
├── manifest.json
└── images/
    ├── 001.png
    ├── 002.png
    └── 003.png
```

这个场景适合包装为：

- 产品发布会 PPT
- 招商加盟 PPT
- 课程培训 PPT
- 汇报总结 PPT
- 路演融资 PPT
- 短视频脚本配套 PPT
- 企业介绍 PPT

### 4.5 战略资源：同橙 OPC 算力超市合作

河马已经与同橙 OPC 算力超市达成合作协议。该合作对河马有三层价值：

1. **模型与算力供给能力**
   河马可以围绕 Agent 任务、生图任务、PPT 生成任务，进一步探索更稳定的模型与算力接入。

2. **成本优化能力**
   PPT 一键生成、多页生图、批量任务执行都会消耗模型和算力。算力超市合作有助于河马在成本、速度和质量之间建立更可控的调度策略。

3. **生态协同能力**
   河马负责 Windows 用户入口、可视化体验、微信连接和 Skill 工作流；同橙 OPC 算力超市提供算力与模型生态协同基础。双方结合后，河马具备从用户入口到能力供给的完整链路想象空间。

这让河马不只是一个前端壳，也不是单一模型工具，而是具备“入口 + 工作流 + 模型供给”的产品结构。

## 6. 差异化优势

### 6.1 我们站在普通 Windows 用户这一边

很多 Agent 产品先服务开发者，河马先服务真实 Windows 用户。这个选择非常关键，因为国内大量高频办公用户并不在开发者工具链里。

河马的目标不是证明 Agent 有多复杂，而是让用户真的装得上、连得上、用得起来、拿得到成果。

### 6.2 微信网关是国内场景的关键入口

微信网关让河马天然靠近国内用户的真实工作流。它不是附加功能，而是产品差异化入口。

用户可以在微信里发起任务，河马在 Windows 电脑上执行任务，再把结果回传。这种体验比单纯网页聊天更接近“AI 助理”。

### 6.3 PPT 一键生成是最强展示场景

PPT 生成能把 Agent 的抽象能力变成可见结果。用户不需要理解 Agent 架构，只要看到一个主题变成一套 PPT，就能理解产品价值。

这是河马早期获客、演示、转化和收费的核心抓手。但商业计划不能把河马收窄成“PPT AI”，PPT 应该被定义为内容产出引擎的第一标杆场景。它负责打开市场认知，后续再自然延展到图片、视频、漫剧、海报、文档和行业内容工作流。

### 6.4 本地场景服务是区别于网页 AI 的护城河

多数 AI 产品停留在浏览器或移动端对话框里，离用户真实电脑环境有距离。河马从 Windows 一键安装进入本地桌面，可以连接文件、目录、脚本、环境、数据和本地知识库。

这会形成三类差异化：

- **高频刚需**：批量文件处理、格式转换、资料归档、环境部署、系统排障都是用户真实会反复遇到的问题。
- **交付更完整**：河马不只生成答案，还能在本地创建文件夹、整理素材、输出 PPTX、图片、文档和压缩包。
- **服务商友好**：本地 AI 服务商可以把河马作为交付底座，为客户部署具体行业工作流。

### 6.5 Skill 是可积累的能力资产

Prompt 容易被复制，Skill 工作流更有沉淀价值。河马可以不断沉淀：

- PPT 工作流
- 微信网关工作流
- 文件整理工作流
- 知识库工作流
- 多源信息聚合工作流
- 专属 Agent 记忆与推荐工作流
- 本地环境部署与运维工作流
- 客服/销售工作流
- 行业模板工作流

用户越用，河马越像一个本地 AI 工作系统，而不是一次性工具。

### 6.6 模型和算力不被单点绑定

河马支持多模型、多 API、中转能力，并已与同橙 OPC 算力超市达成合作协议。我们不会把产品命运绑定在单一模型上，而是用任务调度方式选择更合适的模型与算力供给。

这是长期商业化的关键，因为最终竞争的不只是模型效果，还有成本、稳定性、速度和可持续供给。

## 8. 增长策略

### 8.1 用 PPT 一键生成做传播入口

早期传播不要讲抽象 Agent，要讲结果：

```text
输入主题，河马自动拆大纲、生成视觉页、组装 PPT，最后输出完整文件夹。
```

这句话普通用户能听懂，也愿意转发。

### 8.2 用四类演示建立产品心智

## 11. 竞争壁垒

### 11.1 Windows 一键安装壁垒

把复杂 Agent 能力稳定交付给 Windows 普通用户，本身就是产品工程壁垒。

### 11.2 微信入口壁垒

微信网关让河马进入用户真实沟通场景，而不是停留在独立软件里。

### 11.3 Skill 工作流壁垒

随着场景积累，河马的 Skill 会形成一套可复用 SOP 资产。

### 11.4 算力与模型供给壁垒

与同橙 OPC 算力超市达成合作协议后，河马具备进一步整合模型、算力、API 和成本优化的能力，不会被单一模型供应限制。

### 11.5 交付物壁垒

河马强调最终输出 PPT、图片、文档、文件夹和微信结果，而不是只停留在对话。这是用户愿意付费的核心。

### 11.6 个人上下文与专属 Agent 壁垒

河马一旦沉淀用户的本地文件、日程、兴趣、资讯偏好、学习记录和知识图谱，就会从一次性工具变成长期工作伙伴。专属 Agent 的价值会随着使用次数增加，这是通用聊天产品和一次性内容生成工具很难复制的留存壁垒。

## 15. 路演版电梯陈述

今天很多 AI Agent 很强，但普通 Windows 用户装不上、配不会、用不久。河马要解决这个问题：我们把 Hermes Agent 做成一个 Windows 可视化 AI 工作台，让用户一键安装后就能通过界面或微信调用 AI 完成真实任务。

我们最先打穿的是 PPT 一键生成。用户输入主题，河马自动拆解大纲，用户确认后逐页生成统一视觉页面，并最终输出完整 PPT 文件夹。这不是聊天，这是交付。

河马的优势在于，我们同时抓住了三个关键入口：Windows 本地安装、微信高频触达、Skill 工作流交付。现在我们又与同橙 OPC 算力超市达成合作协议，进一步补齐模型和算力供给侧能力。

我们相信，下一代 AI 产品的竞争不只是模型参数，而是谁能让普通用户真正把 AI 用起来、把任务做完、把成果交付出去。河马要成为国内 Windows 用户进入 AI Agent 时代的第一入口。
